## 📌 The Problem & Ground Reality in J&K

Jammu & Kashmir has over **2 Million+ students** in secondary and higher education, yet fewer than **200 certified career counselors** across the entire Union Territory.

```
  ┌─────────────────────────────────┐      ┌────────────────────────────────┐
  │       2,000,000+ Students       │  ──► │    < 200 Career Counselors     │
  │   Facing information asymmetry  │      │  Severe rural/urban disparity  │
  └─────────────────────────────────┘      └────────────────────────────────┘
                                    │
                                    ▼
  ┌──────────────────────────────────────────────────────────────────────────┐
  │                      THE FIVE CRITICAL BOTTLENECKS                      │
  │  1. Connectivity: Mountainous 2G/3G speeds (0.1–0.5Mbps)               │
  │  2. Complex Schemes: PMSSS, NSP, JKCET — hard to navigate alone        │
  │  3. LLM Hallucinations: Generic AI invents fake deadlines & cutoffs    │
  │  4. No Interview Prep: Zero mock interview infra in remote districts   │
  │  5. High Dropout Risk: 15%+ dropout rates with no early warning system │
  └──────────────────────────────────────────────────────────────────────────┘
```

**J&K EduSetu** bridges this divide with an intelligent, offline-capable, cited advisory system that runs at zero cost on mobile browsers — even under extreme 2G conditions — while offering features previously available only to urban, well-connected students.

## ⚡ Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/Smirk1308/SIH25094.git
cd SIH25094
```

### 2. Set Up Virtual Environment
```bash
python -m venv venv

# Windows:
.\venv\Scripts\activate

# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
```

### 3. Configure API Keys
Create `.streamlit/secrets.toml`:
```toml
GOOGLE_API_KEY = "your_google_gemini_api_key"
GROQ_API_KEY = "your_groq_api_key"          # Optional — used as fallback
ADMIN_PASSWORD = "your_admin_password"       # For admin portal access
```

> **Note**: Without API keys, the app runs in **⚡ 2G Ultra-Lite Offline Mode** with zero crashes. All local features (College Explorer, Scholarship Matcher, Job Explorer) work without any API key.

### 4. Launch
```bash
streamlit run app.py
```
Open `http://localhost:8501` in your browser.

## 🛠️ Tech Stack

| Layer | Technology | Purpose |
|:------|:-----------|:--------|
| **Frontend** | Streamlit 1.42+ | Modern Glassmorphism UI with Plus Jakarta Sans |
| **Primary LLM** | Google Gemini (3.5 Flash Lite / Flash Latest) | 3-tier complexity routing |
| **Fallback LLM** | Groq (Llama 3 8B) | Zero-downtime cloud fallback |
| **Vector Store** | ChromaDB (Persistent, HNSW cosine) | 494+ chunks from 17 documents |
| **Embeddings** | all-MiniLM-L6-v2 (Sentence Transformers) | Local semantic search |
| **PDF Parsing** | pypdf | Document & resume text extraction |
| **Tokenization** | tiktoken (cl100k_base) | 300-token chunks with 50-token overlap |
| **Framework** | LangChain (Google GenAI + Groq) | LLM orchestration |
